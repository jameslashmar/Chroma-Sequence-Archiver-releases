What it does

Finds the waste

Scans in parallel, reading one header per sequence or movie, so it stays quick over SMB. EXR, TIFF, PNG, TGA, DPX and QuickTime/MP4: passes, bit depth, compression, alpha, codec. Search, filter by codec and select hundreds at once.

Shrinks it safely

Picture passes go to DWAA, DWAB or ZIP. Data passes (Z, P, N, motion vectors, IDs, cryptomatte) stay lossless and keep their bit depth.

Checks before it swaps

A sample frame is encoded and measured first. Frame count, headers and pixels are verified, and originals are set aside on the same drive, never deleted, with one-click undo.

Queues the lot

Auto-queue picks the biggest wins for a target saving. Converts movies to MP4 (H.264/HEVC) or ProRes LT/Proxy/4444, warns before alpha would be lost, and makes ProRes 4444, 422 HQ and H.264 proxies with sRGB or ACEScg colour.

Install

  1. Windows: run the -setup.exe installer (or the .msi). It needs Windows 10 or 11 and WebView2, which is already on Windows 11.
  2. macOS: open the .dmg and drag the app into Applications. It is signed with a Developer ID and notarised by Apple. Apple silicon Macs only for now.
  3. Open the app, choose a folder, and press Scan.

OpenImageIO and FFmpeg are bundled; nothing needs to be on your PATH.

Check your download

Each release lists a SHA256SUMS file. Compare it with your download:

# Windows (PowerShell)
Get-FileHash .\Chroma-Sequence-Archiver_*_x64-setup.exe -Algorithm SHA256

# macOS
shasum -a 256 Chroma-Sequence-Archiver_*.dmg

Open-source parts and source offer

The app runs OpenImageIO (oiiotool, Apache-2.0) and FFmpeg as separate programs. The FFmpeg build is the LGPL one: no GPL and no non-free components, and no x264 or x265. The complete FFmpeg source and the build scripts used for each release are published as the ffmpeg-source asset on the releases page. You can swap in your own FFmpeg by setting CSA_FFMPEG.

Every licence notice ships with the app as THIRD_PARTY_NOTICES.txt and is attached to each release.
